# Styling Rules

## CSS Modules
- Use CSS modules (`styles.module.css`) colocated with components
- Import styles as `styles` and use `styles["xyz"]`
- Keep CSS files next to their corresponding components
- Use descriptive class names that reflect their purpose

## Styling Approach
- Prefer CSS modules over inline styles or styled-components
- Maintain consistent naming conventions for CSS classes
- Keep styles modular and component-scoped
- Avoid global CSS when possible
